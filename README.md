# Dolphin34 port of the Urchin keymap

This branch ports Rafiq's 34-position Urchin keymap to the Dolphin34 sold by NomadX. The original Urchin firmware remains on `prime`. The [seller's firmware config](https://github.com/bigeqali/dolphin34/tree/017db149d5379689e5b46533e5381af744cfc7bf) builds with ZMK's in-tree `cradio_left` and `cradio_right` shields, which use the same 3×5+2 key order as Urchin. This branch retains Urchin's layers, combos, home-row mods, and mouse bindings, but builds for Cradio without Urchin's display module.

- Controller: nice!nano-compatible (`nice_nano_v2` in this branch; seller's newer config uses `nice_nano//zmk`).
- ZMK: pinned `v0.2.0`, which includes the Cradio shield and already builds the Urchin keymap. The seller's manifest tracks moving `main`.
- `config/cradio.keymap`: copied from `prime`'s `config/urchin.keymap`, with no binding or position changes.
- `config/cradio.conf`: Bluetooth, pointing, and no-display configuration. Left-only Studio options live in `config/cradio_left.conf`.
- `config/build.yaml` and `flake.nix`: left, right, and settings-reset targets.
- `docs/keymap.html`: generated by `just render-keymap` from `config/cradio.keymap`.

Run through the Nix dev shell:

```sh
nix develop --command just build
nix develop --command just render-keymap
```

`just build` writes these files under `result/`:

- `dolphin34_left-nice_nano_v2-zmk.uf2`
- `dolphin34_right-nice_nano_v2-zmk.uf2`
- `settings_reset-nice_nano_v2-zmk.uf2`

See [docs/flashing.md](docs/flashing.md) **before flashing**. The first install needs both halves flashed and stock firmware backups. A subsequent keymap-only change needs the left/central half only. The flash helper builds first, detects one matching UF2 bootloader, backs up `CURRENT.UF2` read-only on the first flash of each half, then writes the corresponding image. It refuses to flash without an existing backup or a readable `CURRENT.UF2`, unless the right-half backup is explicitly waived with `ZMK_FLASH_SKIP_RIGHT_BACKUP=1`.

The shipped Dolphin keymap enters the Media layer by pressing **both right thumb keys together**. While they are held, press **Q** to enter the left bootloader or **P** to enter the right bootloader. After flashing the left half, use the target half's physical reset button (double-tap) to enter bootloader mode. Do not rely on the factory chord once the central firmware changes. Bootloader ID `239a:00b3` is the nice!nano default, **not yet verified on this Dolphin**; inspect the bootloader USB ID before using `just flash` and set `ZMK_BOOTLOADER_VENDOR_ID`/`ZMK_BOOTLOADER_PRODUCT_ID` if needed.

This is a hardware port, not a source-level clone of the seller firmware. The original ZMK Studio overrides and Bluetooth pairings may need to be reset if they conflict with the new keymap; do not reset either half unless needed.
